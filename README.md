# vibedgames plugins

Claude Code plugins that give a coding agent a game studio's abilities — design, scaffold, generate art and audio, add multiplayer, tune feel, ship.

```sh
claude plugin marketplace add kyh/vibedgames-plugins
claude plugin install vibedgames@vibedgames
```

Skills: [`plugins/README.md`](./plugins/README.md).

**Read-only mirror.** Source of truth is [`kyh/vibedgames`](https://github.com/kyh/vibedgames); this repo is synced from its `plugins/` on every push to main. Open issues and PRs there.
